This is a Next.js app with a bundled Netease sidecar process for QR login and account status checks.

## Development

Run the app and sidecar together:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Production

Build the Next.js app:

```bash
npm run build
```

Start the production app and sidecar together:

```bash
npm run start
```

If you only need the production Next.js server without starting the sidecar, use:

```bash
npm run start:app
```
